## Restricciones del entorno (IMPORTANTES)
- La sesión de herramientas es **no elevada** (`S-1-16-8192`) y con **stdin redirigido**:
  `Start-Process -Verb RunAs` **no puede mostrar UAC** → la elevación automática falla.
  La copia a `wwwroot` la debe lanzar el usuario con el `.bat` (Ejecutar como administrador).
- La herramienta PowerShell **no devuelve stdout** aquí: hay que escribir a un fichero y leerlo.
- `curl` es binario de Windows: para `-F file=@...` hay que usar **ruta Windows** (`D:/...`),
  no rutas MSYS (`/tmp/...`), o falla con exit 26.
- `robocopy` desde Git Bash necesita `MSYS_NO_PATHCONV=1` para que `/MIR` no se convierta en ruta.

## Fallos reales encontrados y corregidos (sólo detectables ejecutando)
1. **`Icon(name, cls)`** — VBScript **NO admite `Optional`** (error "se esperaba un identificador").
   Se dejó `Icon(name)` de un solo argumento (las 72 llamadas usan uno).
2. **`N()`** — `Request.Form(...)`, `Request.QueryString(...)` y `Request.ServerVariables(...)`
   devuelven objetos **`IStringList`** (`IsObject = True`) que sí se convierten con `&`.
   La guarda `IsObject → ""` borraba TODOS los valores de formulario (login roto).
3. **Parámetros ADO** — con `MSOLEDBSQL` y `adCmdText` los parámetros con nombre `@p0`
   fallan ("Must declare the scalar variable @p0"); sólo valen los **posicionales `?`**.
   Solución: `MakeCmd` reescribe `@pN → ?` y repite el valor si el parámetro se usa varias veces.
   Ojo: no declarar una variable llamada `inStr` (tapa la función `InStr`).
4. **`DB_Insert`** — el lote `INSERT...; SELECT SCOPE_IDENTITY()` devuelve el primer resultado
   **cerrado** (error 800a0e78). Hay que avanzar con `NextRecordset` hasta el abierto.
5. **Subida de archivos** — `MidB` devuelve **String**, y `ADODB.Stream.Write` en binario exige
   **array de bytes** (error 3001). Se guardan las coordenadas del fragmento en `m_data` y se
   extrae el array con un Stream (verificado **byte a byte**, 10 240 B idénticos).
6. **`Server.MapPath`** no garantiza barra final → `root & "f.mp3"` daba siempre falso y **toda**
   imagen/audio caía al recurso por defecto. Corregido añadiendo el separador.
7. **IDOR en `playlists.asp`** — el propietario venía de un campo oculto del formulario: un usuario
   normal podía editar playlists ajenas, y no podía borrar las suyas. Ahora se lee de la BD
   (`PlaylistOwnerId`).
8. **`EnsureAppRoot`** — si la app es un simple subdirectorio de `wwwroot`, `APPL_MD_PATH` vale
   `/LM/W3SVC/1/ROOT` y la base quedaba vacía (CSS y enlaces sin `/PoliMusic/`). Ahora usa
   `SCRIPT_NAME` como respaldo. Verificado en ambos despliegues (raíz y `/PoliMusic/`).
9. **`profile.asp`** — `DB_Count(..., Array())` con `@p0` en el SQL: el error se tragaba
   `On Error Resume Next` y mostraba 0 canciones. Corregido a `Array(g_UserID)`.
